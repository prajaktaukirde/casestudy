# Portfolio Dashboard

A dynamic stock portfolio tracker built with Next.js, TypeScript, and Node.js. It fetches live market prices from Yahoo Finance and fundamentals from Google Finance, refreshing data every 15 seconds.

## How to Run

1. **Backend:** `cd backend && npm start` (runs on http://localhost:5000)
2. **Frontend:** `cd frontend && npm install && npm run dev` (runs on http://localhost:3000)
